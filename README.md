# swept-path

Simulateur d'épure de giration : vérifier qu'un véhicule peut franchir un
passage étroit — portail, entrée de cour, box de parking — et en combien de
manœuvres.

- `CLAUDE.md` — contexte, modèle géométrique, décisions prises, défauts connus
- `docs/SPEC.md` — spécification fonctionnelle et périmètre à construire
- `prototype/index.html` — prototype de référence, monofichier sans
  dépendance, à ouvrir directement dans un navigateur
- `data/vehicles.json` — amorce de base véhicules, provenance par champ
